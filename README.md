# FHIR Directory Neo4j
Tools to work with FHIR based provider/payer/healthsystem data using neo4j

Intended to support data from [NDH FHIR servers](https://build.fhir.org/ig/HL7/fhir-us-ndh/en/) and [DaVinici PDex PlanNet](https://build.fhir.org/ig/HL7/davinci-pdex-plan-net/en/) servers

Code is experimental/alpha

Look in README_neo4j.md for details on how to work with this project.
